This subfolder contains the Python code for fitting the 5-equation model: V = annual realized daily S&P volatility, 1928-2025; 
R = Bank of America ICE BAA rate, December daily average, 1927-2025; F = Yeo-Johnson transform with index -0.5

F(ln V) and F(R) modeled each as an autoregression of order 1, but F(ln V) is mean-reverting while F(R) fail to reject unit root

geometric US and international stock returns are modeled as Q(t) = a - d(R(t) - R(t-1)) + V(t)Z(t), and bond returns are modeled as 
Q(t) - 0.01R(t-1) = a - d(R(t) - R(t-1)) + Z(t)

Data: US stocks: S&P, 1928-2025; International stocks: 12% MSCI Canada + 88% MSCI EAFE, 1970-2025; Bonds: US BofA corporate bonds, 1973-2025

All returns are annual (not monthly); total (including dividends); and nominal (not adjusted for inflation)

All five series of residuals are Gaussian, so we model this as multivariate Gaussian, which enables us to do objective Bayes inference

fit.py fitting all these regressions and printing Bayes covariance matrices for the posteriors; classic.py frequentist simulation; 
bayes.py objective Bayes simulation; app.py printing PDF and PNG output; test.py is execute all the above

Each has 10000 simulations. Classic simulator is fine, but the Bayes one explodes
